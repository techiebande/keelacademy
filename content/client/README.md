# The client folder

Every lesson and every assignment uses the files here. Nothing about Lantern Home lives anywhere else, so if a lesson mentions an order number, a customer, or a rule, you can find it in this folder.

- `brief.md`: who Lantern is, who the three people are, and what problem the course solves for them. Unit 0.1 is built on it.
- `rules.md`: the support team's rulebook, twenty rules. Phase 4 grounds answers in it; Phase 1 reads it as a text file.
- `messages/`: ten customer messages, one per file, in the plain-text form the support inbox exports. Some include an order number, some do not. Some have typos. That is the point.
- `orders.csv` and `deliveries.csv`: the shop's order table and the courier's delivery record.

Keep the data small enough to read by eye. A student should be able to open any file here and check a program's output against it by hand. When a later unit needs more volume, it generates it from these and says so.
