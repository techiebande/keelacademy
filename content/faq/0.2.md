# Unit 0.2 unstuck notes

## How many rows does my table need? {#how-many-modules}

The table needs exactly 56 rows, one per module. The curriculum has 13 phases. The phases together have 56 modules.

To count your rows: open your file and count the lines between the header row separator and the end of the table. Each line that starts with `|` is one row. The header row and the separator row do not count.

Before: A table with 8 rows (only Phase 0 and Phase 1).

After: A table with 56 rows, from 0.1 down to 12.4.

If you are not sure which modules exist, look at the lesson's text block. It lists every phase and how many modules each one has.

## My column names keep failing the check. What does the check look for? {#column-names-exact}

The check looks for these four names, spelled exactly like this and in this order:

```
Module | Status | Hours spent | Deliverable
```

The check is case sensitive. "Status" passes. "status" fails. "Hours Spent" fails because the S is a capital letter. "Time" fails because it is a different word.

Before: `| Module | State | Time | Link |`

After: `| Module | Status | Hours spent | Deliverable |`

Copy the header line from the template and do not type it by hand.

## What do I write in the Deliverable column for a module I have not reached yet? {#deliverable-not-yet}

Write `(not yet)` in the Deliverable column for any module you have not started. Do not leave the cell blank. A blank cell looks like a missing column to the check.

Before: `| 3.1 | not started | 0 |  |`

After: `| 3.1 | not started | 0 | (not yet) |`

Once you finish a module and turn in a file, replace `(not yet)` with the path to that file, like `omnicart-system/docs/client-brief.md`.
