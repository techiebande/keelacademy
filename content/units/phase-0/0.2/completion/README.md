- Keel Academy has 13 phases, numbered 0 to 12.
- The phases together have 56 modules.
- Phase 0 has three modules: 0.1, 0.2, and 0.3.

- Status can be: not started, in progress, or done.

## The rules

1. Your tracker must cover all 56 modules, one row per module.
2. Use these four column names, spelled exactly like this and in this order:
   `Module`, `Status`, `Hours spent`, `Deliverable`.
   The column names are case sensitive. Type them exactly as shown.
3. Every row must have a non-empty status. Write "not started" when you have not begun.
4. Phase 0 must be marked done. Module 0.1 is your client brief. Module 0.2 is this tracker. Module 0.3 is the Docker setup.
5. The deliverable column for module 0.2 must say `omnicart-system/docs/progress-tracker.md`.
6. Do not add extra columns or leave any row blank.

A row may use "(not yet)" in the deliverable column when you have not produced a file. Do not leave it empty.

## The four checks

Your tracker is graded on four checks, and all four must pass.

1. All 56 modules appear, one row each, with no duplicates.
2. The four column names are present and spelled exactly right.
3. Phase 0 rows are all marked done.
4. The deliverable column for module 0.2 says the correct file path.

The other rules help you pass these four.
